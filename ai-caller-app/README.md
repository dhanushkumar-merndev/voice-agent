# Star AI Caller (Android)

Flutter app: pick a sector, enter a number, tap Call. A Vapi AI agent phones the person,
asks the sector's questions in Hinglish or English, and the app shows the recording,
call description, captured details and full conversation.

Built by GitHub Actions on the `ai-caller-apk` branch; the latest APK is committed to
`release/star-ai-caller.apk`. Scripts live in `lib/agent.dart`.
